= BOM Results Publisher


This service receives BOM test result data from Jenkins CI jobs and stores them
as JSONL records in a GitHub repository. It acts as a trusted middleman:
Jenkins POSTs results using a preshared bearer token, and the service uses a
GitHub App to commit the data — so no storage credentials ever need to be
configured on the (untrusted) CI instance.

The data originates from the `bom-report.txt` file produced by the
link:https://github.com/jenkinsci/bom[jenkins-infra/bom] test harness, which
records per-plugin test metrics in `key=value;` format.


[[env]]
== Environment Variables

|===
| Variable | Description

| `GITHUB_APP_ID`
| The App ID for the GitHub App used to commit results

| `GITHUB_APP_PRIVATE_KEY`
| The private key for the GitHub App

| `GITHUB_APP_INSTALLATION_ID`
| The installation ID for the organisation/user account the App is installed on (defaults to `22187127`)

| `GITHUB_OWNER`
| GitHub organisation owning the results repository (defaults to `jenkins-infra`)

| `GITHUB_REPO`
| GitHub repository where results are stored (defaults to `results-publisher`)

| `RESULTS_FILE_PATH`
| Path within the repository to the JSONL file (defaults to `data/bom-results.jsonl`)

| `PRESHARED_KEY`
| Bearer token required to authenticate POST requests from Jenkins

| `PORT`
| Port to listen on (defaults to `3000`)

|===


== API

=== `POST /bom-results`

Accepts the content of a `bom-report.txt` file and appends parsed records to
the configured JSONL file in GitHub.

*Authentication*: `Authorization: Bearer <PRESHARED_KEY>`

*Request body* (`application/json`):

[source,json]
----
{
  "results": "<raw bom-report.txt content>"
}
----

Each line of `results` must follow the `key=value;` format produced by the BOM
test harness, for example:

----
name=aws-credentials-plugin:weekly;failCount=0;skipCount=0;passCount=8;totalCount=8;duration=15.298;elapsed=39.122;plugins=[aws-credentials];pluginCount=1;attempt=1;build_id=21;job_base_name=PR-7078;short_commit_id=d73ef89
----

*Response*: `200 OK` with `{ "stored": <count> }` on success.

=== `GET /liveness`

Returns `200 OK` with `{ "status": "OK", "version": "..." }`.

=== `GET /readiness`

Returns `200 OK` with `{ "status": "OK" }`.

== Example request

[source,bash]
----
curl -X POST http://localhost:3000/bom-results \
  -H "Authorization: Bearer ${PRESHARED_KEY}" \
  -H "Content-Type: application/json" \
  -d '{
    "results": "name=foo-plugin:weekly;failCount=0;skipCount=0;passCount=8;totalCount=8;duration=15.298;elapsed=39.122;plugins=[foo];pluginCount=1;attempt=1;build_id=21;job_base_name=PR-1;short_commit_id=abc1234"
  }'
----
