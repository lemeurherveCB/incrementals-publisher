= BOM Results Publisher


This service receives BOM test result data from Jenkins CI jobs and stores them
as plain text files, one per build, in an Azure File Share. It acts as a
trusted middleman: Jenkins POSTs results using a preshared bearer token, and
the service uses Azure credentials — so no storage credentials ever need to be
configured on the (untrusted) CI instance.

The data originates from the `bom-report.txt` file produced by the
link:https://github.com/jenkinsci/bom[jenkins-infra/bom] test harness.

Files are stored at `{controller}/{job_name}/{build_id}.txt`, where
`controller` is the hostname of the Jenkins instance extracted from
`BUILD_URL` (e.g. `ci.jenkins.io`). The file
`{controller}/{job_name}/latest.txt` is also updated on every call.


[[env]]
== Environment Variables

|===
| Variable | Description

| `PRESHARED_KEY`
| Bearer token required to authenticate POST requests from Jenkins

| `PORT`
| Port to listen on (defaults to `3000`)

| `AZURE_STORAGE_ACCOUNT`
| Azure Storage account name

| `AZURE_STORAGE_SHARE`
| Name of the Azure File Share

| `AZURE_STORAGE_KEY`
| _(optional)_ Azure Storage account key. When unset, `DefaultAzureCredential` is used (workload identity on AKS, `az login` locally).

|===

NOTE: On AKS with workload identity, leave `AZURE_STORAGE_KEY` unset and assign
the identity the `Storage File Data SMB Share Contributor` role on the storage
account.


== API

=== `POST /bom-results`

Accepts BOM test results for a single build and stores them as a plain text
file.

*Authentication*: `Authorization: Bearer <PRESHARED_KEY>`

*Request body* (`application/json`):

[source,json]
----
{
  "build_url": "<Jenkins BUILD_URL, e.g. https://ci.jenkins.io/job/Plugins/job/bom/job/PR-1/21/>",
  "results": "<raw bom-report.txt content>"
}
----

*Response*: `200 OK` on success.

=== `GET /liveness`

Returns `200 OK` with `{ "status": "OK", "version": "..." }`.

=== `GET /readiness`

Returns `200 OK` with `{ "status": "OK" }`.

== Example request

[source,bash]
----
curl -X POST http://localhost:3000/bom-results \
  -H "Authorization: Bearer ${PRESHARED_KEY}" \
  -H "Content-Type: application/json" \
  -d '{
    "build_url": "https://ci.jenkins.io/job/Plugins/job/bom/job/PR-1/21/",
    "results": "name=foo-plugin:weekly;failCount=0;skipCount=0;passCount=8;totalCount=8;duration=15.298;elapsed=39.122;plugins=[foo];pluginCount=1;attempt=1;build_id=21;job_base_name=PR-1;short_commit_id=abc1234"
  }'
----
